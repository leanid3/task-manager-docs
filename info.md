# Настройка dev соединения по git

## Запуск
### Войти в gitea аккаунт:
   1) подключиться по vpn
   2) в браузере перейти на http://192.168.78.61:4925
   3) войти под доступами gitea, которые выдали

### авторизация по ssh
 1)  создать ssh ключ(если нет):
        ```bash
            ssh-keygen
        ```
 2) скопировать ключ(по умолчанию ~/.ssh/id_ed25519):
    ```bash
        cat ~/.ssh/id_ed25519
    ```
3) добавить ключ в аккаунт на gitea:  Аккаунт->Настройки->Ключи SSH/GPG -> Добавить ключ(вставте ssh ключ)

### Клонирование репозитория
 1) Указать точное название, особенно ПОРТ SSH:
    ```bash
    git clone ssh://git@{host}:{port SSH}/{organization}/{repository}.git
    ```


## Разное
### Как изменить порт/host/runner для деплоя:
1) Порт: зайти в репозиторий->настройки->действия->переменные->{service}_PORT
2) HOST/runner - зайти в репозиторий->настройки->действия->раннеры/переменные->добавить
