## Миграция бд для локалки и прода

### Локаль

**Принцип**:
1) Команды для работы, все описано в makefile:
```bash
    #Переменные окружения
    migrate_dir - директория внутри мигратора, откуда будут считаны файлы sql

    #Команды
    migrate-create name={название:task} - создается новую версию миграции - sql файл для миграции
    migrate-delete version={версия:000001} - удалить миграцию по версиям
    migrate-up - выполнить миграцию всех версий
    migrate-down - откатить миграцию до прошлой версии
    migrate-status - узнать статус 
    migrate-version - узнать версию
    migrate-force version={номер:3} - принудительно установить весрию миграции

```
2) написать sql разментку в созданных файлах и применить команды выше

#### Конфигурация:
- должен быть в docker-compose:
    ```yml
        migrate:
        image: migrate/migrate:latest
        container_name: migrate
        depends_on:
        postgres:
            condition: service_healthy
        volumes:
        - {'путь до диектории с файлами миграции'}:/migrations
        user: "1000:1000"
        networks:
        - document-flow-network
        restart: "no"
    ```

### Примечаени:
 - Если существуют таблицы из нескольких версий и нужно удалить старую таблицу, а версия новая, то нужно создать новую миграцию с drop table {таблица}. История событий нужно соблюдать!
